# 游戏成瘾社会机制两阶段任务：jsPsych 试测版

## 研究目标

检验游戏成瘾倾向的社会机制是否至少包含两条可区分路径：

1. 回避—补偿路径：社会受挫后更少寻求互动，或更倾向低风险、低关系承诺的互动；
2. 游戏社会嵌入路径：社会需求更多通过稳定的游戏内关系获得满足，并与问题性游戏使用相关。

本程序把“是否社交”和“如何社交”分成两个连续决策阶段。它是用于检查材料、程序和指标可行性的试测版，不是最终正式实验。

## 当前任务结构

- 2 个练习情境；
- 24 个正式情境：12 个社会受挫、12 个中性；
- 每个情境均回答：
  - Stage 1：独自活动 vs 与他人互动；
  - Stage 2：若通过游戏互动，选择现实朋友、游戏好友或陌生玩家；
- Stage 2 对所有 trial 都呈现，避免只分析“本来就愿意社交”的被试造成选择偏差；
- 记录每题选择、反应时、呈现顺序、情境条件与设备信息；
- 任务后收集 IGDS9-SF 试测中文表述及 6 个探索性社会题目。

## GitHub Pages 部署

1. 在 GitHub 新建公开仓库，例如 `igd-social-pilot`。
2. 上传本文件夹内所有文件到仓库根目录。
3. 进入 `Settings → Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待约 1–3 分钟，实验地址通常为：
   `https://你的GitHub用户名.github.io/igd-social-pilot/`

GitHub Pages 只负责呈现实验，不能自动把数据保存到研究者端。当前试测采用“完成后自动下载 CSV”，被试需把文件发给研究者。正式收数时建议接入 JATOS、DataPipe 或院系服务器，并重新走知情同意与数据管理审核。

## 小样本试测建议

- 先收 8–15 人，重点不是显著性，而是检查：完成时长、漏答、反应时异常、选项是否天花板/地板、社会受挫材料是否有效；
- 不建议在这一阶段按 IGD 高低分组；使用连续 IGD 总分；
- Stage 1 初步模型：`seek_social ~ condition * igd_total + (1|participant)`；
- Stage 2 初步描述：三类渠道比例；正式分析可用混合效应多项逻辑回归；
- 若试测人数很少，先只报告每人的比例、条件差值和散点图，不对 p 值作强解释。

## 关键变量

- `participant_id`：随机被试编号；
- `research_code`：研究者提供的编号；
- `condition`：`social_setback` / `neutral`；
- `task`：`stage1_seek_social` / `stage2_channel`；
- `seek_social`：阶段1选择互动=1，独自=0；
- `channel_code`：`offline_friend` / `game_friend` / `stranger`；
- `game_embedded_choice`：选择游戏好友=1；
- `rt`：反应时（毫秒）；
- `igd_total`：9题总分（9–45）。

## 使用限制

- 当前社会受挫材料尚未经过独立样本评定；正式实验前应评定负性、社会评价/排斥感、唤醒度和熟悉度。
- 6个社会题目是探索性占位题，不能当作已验证量表使用。
- IGDS9-SF 中文措辞应在正式研究前替换为获得授权或文献中验证过的正式版本。
- 手机可运行，但涉及反应时比较时建议正式实验限制电脑端。
