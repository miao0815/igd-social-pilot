# 游戏成瘾社会机制异质性研究：V3.2.1 DataPipe试测程序

## 当前研究问题

研究游戏成瘾倾向者在社会需求满足方式上是否存在不同模式，例如现实关系较弱、更多依赖替代性渠道的模式，以及游戏内拥有稳定伙伴、归属和支持的游戏社会嵌入模式。V3不把“社会受挫后是否用游戏逃避”作为实验操纵，也不设置受挫—中性条件。

## 行为任务

1. 日常活动选择：12个不同的社会需要/机会情境与6个填充情境，计算社会趋近比例；
2. 娱乐选择：6个明确的多人游戏情境与2个填充情境，区分独自游戏、现实朋友、固定游戏好友和陌生玩家；
3. 两个模块彼此独立，不再在每个trial后反复追问“如何互动”。

## 降低目的察觉

- 对外名称为“大学生日常活动与娱乐选择研究”；
- 情境涵盖分享、陪伴、建议、合作、娱乐和普通日常，不以负面问题为主；
- 填充题与关键题混合随机呈现；
- 研究问卷全部放在行为任务之后；
- 目的猜测题放在问卷之前，避免被问卷提示。

## 试测指标

- `social_approach_rate`：日常情境中选择联系他人的比例；
- `solo_game`、`real_friend`、`game_friend`、`stranger`：游戏伙伴选择比例；
- `igd_total`、`embed_total`、`real_total`：试测问卷得分。

当前游戏社会嵌入和现实关系题为自编试测题，正式研究前必须完成量表选择、材料评定和伦理审核。少量同学试测只能用于检查目的察觉、题意、选择分布和时长，不能用于正式划分亚型。
